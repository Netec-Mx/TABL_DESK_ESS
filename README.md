# Tableau Desktop

## Plataforma de laboratorios

Te damos la bienvenida a la **plataforma de laboratorios** del curso **Tableau Desktop**. Aquí podrás explorar diferentes tecnologías a través de prácticas guiadas. 
¡Desarrolla tus habilidades y lleva tus conocimientos al siguiente nivel!

## Lista de laboratorios

Cada uno de estos laboratorios está diseñado para ofrecerte una experiencia práctica. Haz clic en los enlaces para comenzar.

### [Práctica 1. Conexión y preparación de datos](Capítulo1/README.md) 
- **Descripción**
   - Conectarte a una fuente de datos en Tableau Desktop y abrir la sesión inicial.
   - Visualizar la página de `Conectar` en Tableau, elegir un conector y vincular el conjunto de datos `Muestra - Supertienda`. 
   - Ver la interfaz de fuente de datos: observar la hoja de trabajo en blanco, la lista de campos, los tipos de dato y roles que asigna automáticamente Tableau.
- ⏱️ **Duración estimada: 30 min.

### [Práctica 2. Creación de visualizaciones básicas](Capítulo2/README.md)
- **Descripción**
   - Crear una vista.
   - Refinar una vista.
- ⏱️ **Duración estimada**: 40 min.

### [Práctica 3. Análisis y filtros en Tableau](Capítulo3/README.md)
- **Descripción**
   - Centrarte en los datos relevantes mediante filtros y colores para analizar con mayor precisión los resultados en Tableau Desktop.
   - Analizar las tendencias geográficas de ventas y rentabilidad creando una vista de mapa en Tableau para visualizar patrones por región.
   - Profundizar en el análisis filtrando los datos para centrarse en los estados con pérdidas y descubrir las causas de las ganancias negativas.
- ⏱️**Duración estimada**: 90 min.

### [Práctica 4. Dashboards e historias](Capítulo4/README.md) 
- **Descripción**
   - Diseñar dashboards efectivos.
   - Añadir interactividad a los dashboards.
   - Crear historias en Tableau.
- ⏱️ **Duración estimada**: 60 min.

### [Práctica 5. Análisis avanzado](Capítulo5/README.md)
- **Descripción**
   - Diseñar visualizaciones avanzadas.
   - Crear un dashboard con gráficas y análisis avanzados.   
- ⏱️ **Duración estimada**: 120 min.

### [Práctica 6. Implementación de una integración con R o Python](Capítulo6/README.md)
- **Descripción**
   - Aprender comandos básics de R o Python.
   - Ejecutar scripts de R o Python sobre Tableau.
- ⏱️**Duración estimada**: 60 min.

### [Práctica 7. Proyecto final](Capítulo8/README.md) 
- **Descripción**
   - Conectar orígenes de datos.
   - Realizar transformaciones.
   - Crear vistas.
   - Diseñar dashboards.
- ⏱️ **Duración estimada**: 120 min.
